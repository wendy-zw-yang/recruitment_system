# 汇聘系统使用手册

> 本文件仅收录面向求职者与 HR 用户的功能说明，不包含任何系统内部实现细节。
> 最后更新：2026-10-06

---

## 求职者篇

### 1.1 如何注册求职者账号？

进入首页 → 点击右上角「免费注册」→ 填写邮箱、密码、确认密码 → 选择身份「求职者」 → 点击「注册」按钮。注册成功后自动跳转到登录页。

### 1.2 如何登录？

登录方式有两种：
1. **密码登录**：进入登录页，输入邮箱 + 密码 → 点击「登录」。
2. **验证码登录**：切换到「验证码登录」标签 → 输入邮箱 → 系统会向你的邮箱发送验证码（或在演示模式下打印到后端控制台）→ 输入验证码 → 点击「登录」。

### 1.3 如何上传简历？

进入「我的简历」页面 → 在上传卡上拖入或选择简历文件（支持 PDF 或 Word 格式，不超过 20MB）→ 系统会自动识别简历内容并填入表单（约 5-15 秒）→ 进入查看模式，可继续编辑或保存。

注意：上传解析仅在首次上传时触发一次；之后修改简历不会再触发自动解析。

### 1.4 上传后 AI 解析失败怎么办？

常见原因与处理：
1. **文件格式不支持**：请改用 PDF（.pdf）或 Word（.docx）格式重新上传。
2. **文件过大**：请压缩文件至 20MB 以内再上传。
3. **简历是图片扫描件**：目前不支持图片识别，请改为文字版 PDF / Word 后重新上传。

### 1.5 如何编辑已上传的简历？

进入「我的简历」→ 点击底部「编辑」按钮 → 修改基本信息、自我介绍、教育 / 工作 / 项目经历 → 点击「保存」。

### 1.6 如何重新上传简历（替换附件）？

进入「我的简历」→ 点击底部「重新上传」按钮 → 确认后系统会归档当前简历并打开上传页 → 选择新文件上传。旧简历会保存为历史版本。

### 1.7 如何删除简历？

进入「我的简历」→ 点击底部「删除」按钮 → 确认后删除。删除后可立即重新上传。

### 1.8 如何搜索职位？

进入「职位」页面 → 在顶部搜索栏输入关键词（如"Java"、"产品"、"市场"） → 可选填城市 → 点击「搜索」按钮。

注意：搜索栏输入或选择条件不会立即触发，需要点击「搜索」按钮或按回车键。

### 1.9 如何筛选职位？

支持以下筛选：
- **关键词**：职位名 / 公司名 / JD 内容
- **城市**：文本输入（深圳 / 北京 等）+ 二级下拉（省份 → 城市）
- **行业**：行业下拉选择
- **只看收藏**：仅显示你收藏过的职位（需登录）
- **排序**：最新发布 / 按薪资等

点击「✕ 清除筛选」按钮可一键清空所有筛选条件。

### 1.10 如何收藏职位？

进入职位详情页 → 点击右上角⭐图标即可切换收藏。列表页每个职位卡也支持收藏按钮，点击即时切换。

注意：未登录用户不能使用收藏功能。

### 1.11 如何投递职位？

浏览职位 → 点击「查看详情」→ 在职位详情页点击「立即投递」按钮 → 弹出投递确认弹窗（可选填求职信）→ 点击「确认投递」→ 投递成功，跳转到投递详情页。

注意：
- 投递前必须先上传简历（详见 1.3）；
- 同一职位只能投递一次；
- 投递后 HR 会逐步处理，可在「我的投递」查看进度。

### 1.12 投递后多久能收到回复？

投递后立即看到初始状态「待 HR 查看」。HR 处理后会依次经历：已查看 → 简历通过 → 面试中 → 已发 Offer → 已入职。每一步状态变更都会反映在「我的投递」中。

### 1.13 如何撤回投递？

进入「我的投递」→ 找到要撤回的投递 → 点击右侧「撤回」按钮 → 确认 → 撤回成功。

注意：撤回后不可恢复；终态（已入职 / 已拒绝 / 已撤回）的投递不能再撤回。

### 1.14 我的投递有哪些状态？

| 显示 | 含义 |
|---|---|
| 待 HR 查看 | 你已投递，HR 还没处理 |
| 处理中 | HR 已查看简历 |
| 简历通过 | HR 通过了简历筛选 |
| 面试中 | HR 邀请你面试 |
| 已发 Offer | HR 已发入职邀请 |
| 已入职 | 已完成入职 |
| 已拒绝 | HR 拒绝（终态） |
| 已撤回 | 你撤回了投递（终态） |

### 1.15 如何修改个人信息？

点击右上角头像 → 「个人中心」→ 「个人资料」标签 → 修改用户名 / 电话 → 点击「保存个人资料」。

注意：邮箱不可修改（是登录凭证）；头像由系统按 user_id 自动生成，不可更改。

### 1.16 如何修改密码？

个人中心 → 「账号安全」标签 → 输入旧密码、新密码、确认新密码 → 点击「修改密码」。

新密码长度要求 ≥ 6 位。

### 1.17 如何设置求职偏好？

个人中心 → 「求职偏好」标签 → 输入「期望职位」（如"Java 开发工程师"）→ 点击「保存求职偏好」。

### 1.18 找不到菜单 / 按钮？

- 顶部导航栏在所有页面恒定显示，点击对应菜单跳转。
- 个人中心：右上角头像 → 个人中心。
- 常见功能（简历、职位、我的投递、消息）都在顶部导航。

## HR 篇

### 2.1 如何注册 HR 账号？

进入注册页面 → 填写邮箱、密码 → 选择身份「HR」 → 同步填写公司名称、所属行业、公司规模、公司简介 → 点击「注册」。

注意：HR 注册时公司信息必填；注册成功立即可用全部功能，公司信息审核由管理员事后巡查。

### 2.2 如何发布职位？

进入 HR 首页 → 点击「发布新职位」按钮 → 在职位编辑抽屉填写：标题 / 行业 / 省份 / 城市 / 薪资范围 / 岗位职责 / 任职要求 / 福利待遇 → 点击「AI 一键润色」（可选）或手动保存 → 草稿保存后点击「上线」按钮发布。

### 2.3 AI 润色 JD 怎么用？

职位编辑抽屉 → 在「关键词」输入框填写 3-5 个关键词 → 点击「AI 一键润色」按钮 → AI 自动生成完整 JD（包含职责 / 要求 / 福利）→ 人工微调后保存。

注意：AI 润色需要后端已配置 AI 服务；失败时可手动填写。

### 2.4 如何查看候选人投递？

进入「简历收件箱」→ 默认显示该 HR 所有职位的最新投递（按投递时间倒序）→ 顶部下拉可按职位过滤 → 输入关键词可搜索候选人 → 勾选「显示已撤回」可看到已撤回的记录（默认折叠显示）。

投递卡片显示候选人姓名、投递时间、当前状态、AI 评分（仅 HR 可见）。

### 2.5 如何推进候选人状态？

进入投递详情页 → 右侧「推进状态」区域 → 选择目标状态（已查看 / 简历通过 / 面试中 / 已发 Offer / 已入职 / 已拒绝）→ 点击「推进」按钮。

状态流转规则：
- 待 HR 查看 → 已查看 / 已拒绝
- 已查看 → 简历通过 / 已拒绝
- 简历通过 → 面试中 / 已拒绝
- 面试中 → 已发 Offer / 已拒绝
- 已发 Offer → 已入职 / 已拒绝
- 终态（已入职 / 已拒绝）不能再推进

### 2.6 如何添加候选人备注？

进入投递详情页 → 右侧「备注」区域 → 输入备注内容 → 点击「添加备注」。

每条备注可随时编辑或删除（仅你自己可见）。

### 2.7 如何查看候选人简历？

进入投递详情页 → 点击「加载候选人简历」按钮 → 弹出简历内容（基础信息 / 技能 / 教育 / 工作 / 项目）。

注意：你看到的是候选人投递瞬间的简历副本，后续候选人编辑或删除简历不影响你看到的快照。

### 2.8 如何修改公司信息？

点击右上角头像 → 「个人中心」→ 「我的公司」标签 → 修改公司名 / 行业 / 规模 / 简介 → 点击「保存」。

修改后公司重新进入待审核状态。

## AI 智能客服

### 3.1 AI 客服在哪里？

登录后页面右下角有「💬 AI 客服」悬浮按钮，点击即可展开聊天面板。

### 3.2 AI 客服能做什么？

AI 客服能回答：
- 系统功能操作（注册、简历、投递、收藏、个人中心等）
- 状态流转规则（投递状态含义、HR 操作流程）
- 常见错误处理（解析失败、密码修改等）

### 3.3 AI 客服的回答准确吗？

- 命中手册的问题：基于系统内置的使用手册回答，准确度高；
- 手册未覆盖的问题：AI 会基于通用知识回答，可能存在偏差，建议结合实际操作验证；
- AI 客服不会主动编造 URL / 按钮 / 接口路径。

### 3.4 如何提问获得准确回答？

- 用简短关键词提问（如"如何投递"、"如何修改密码"）；
- 提问具体功能而非主观问题；
- 不要长篇提问。

### 3.5 如何清空对话历史？

聊天面板顶部「🗑 清空」按钮 → 确认 → 历史清空。

### 3.6 如何新建一个对话？

聊天面板顶部「↻ 新建会话」按钮 → 确认 → 新开一段对话，旧对话保留。

### 3.7 历史对话会保留多久？

长期保留（除非你主动清空或账号被删除）。关闭浏览器再打开会自动恢复当前会话的历史（最近 20 条）。

### 3.8 AI 客服响应慢怎么办？

- 首次响应 1-3 秒属正常范围；
- 持续超过 10 秒可能是网络问题或 AI 服务繁忙，建议刷新重试。

## 通用问题

### 4.1 页面报错怎么办？

- 401：未登录或登录已过期，请重新登录
- 403：无权限（角色不符）
- 404：资源不存在
- 500：服务器异常，请稍后重试

### 4.2 找不到页面？

URL 错误或页面已被移除。请通过顶部导航或首页进入目标功能。

### 4.3 数据是否实时同步？

是。绝大多数数据保存后立即生效；刷新页面会重新拉取最新数据。

### 4.4 怎么反馈问题？

页面右上角的 AI 客服可解答大部分功能问题；如需人工支持，请联系平台管理员。
