## 追加 · 需求分析微调（字典策略）

### 文件变动

- docs/需求分析.md v0.1 → v0.2

### 改动内容

经用户提问后调整字典策略：

- 行业字典：保留为强制下拉（管理员维护）
- 城市字典：保留为强制下拉（管理员维护）
- **技能字典改为可选建议池**（dict_skill_suggestion），不再强制下拉
  - 用户可自由输入任意技能词
  - 前端基于建议池做自动补全，但建议池不强制
  - 不维护严格白名单
- 筛选维度去掉"按技能"，改为"技能关键词搜索"
- 详细搜索规范化（大小写、空格、子串匹配）方案留到模块设计 / 数据库设计阶段再定

### 理由

用户提出：
1. 技能跨行业（CS / 金融 / 医疗 ...）数量爆炸，全行业字典维护成本不现实
2. 强制下拉反而限制用户表达
3. 后端搜索做规范化即可解决"java / Java / JAVA"统一识别问题
4. 失去"按技能精确统计"能力，对课程项目无影响
