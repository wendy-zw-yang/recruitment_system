## 0. 说明

本 WBS 按**功能模块**维度分解系统交付物，与时间维度文档 `docs/系统设计/WBS/进度计划.md` 配套使用（PMBOK 标准：1 个 WBS + 1 个 Schedule）。

- WBS ID：X.Y.Z，X = 一级模块编号，Y = 子模块，Z = 任务
- 每个任务列出**交付物**（代码 / 文档 / 配置）和**依赖**（前置 WBS 节点）

## 1. 用户与认证

### 1.1 注册
- 1.1.1 求职者注册（邮箱 + 密码）
- 1.1.2 HR 注册（邮箱 + 密码 + 公司信息）
- 1.1.3 管理员账号预置
- 1.1.4 邮箱验证码（`app.mail.enabled` 开关）
- **交付物**：AuthController、AuthService、email_code 表、注册页面
- **依赖**：8.1 JWT、8.2 BCrypt、8.5 数据库

### 1.2 登录
- 1.2.1 密码登录
- 1.2.2 验证码登录
- 1.2.3 JWT 签发与校验（jjwt 0.12.x）
- **交付物**：AuthController、JwtFilter、LoginRequest DTO
- **依赖**：1.1 注册、8.1 JWT

### 1.3 账号设置
- 1.3.1 账号安全（邮箱 / 密码）
- 1.3.2 个人资料（姓名 / 电话 / 头像）
- 1.3.3 求职偏好（候选人）
- 1.3.4 HR 个人信息 + 我的公司（链接 7.2）
- **交付物**：AccountController、ProfileEdit 页面
- **依赖**：1.1 注册

### 1.4 头像生成
- 1.4.1 SVG 实时渲染（user_id 哈希取色 + 姓名首字母）
- 1.4.2 头像缓存层（可选）
- **交付物**：AvatarUtil、Avatar.vue
- **依赖**：1.1 注册

### 1.5 候选人搜索（HR / 管理员）
- 1.5.1 候选人列表（限定已投递）
- 1.5.2 筛选 / 搜索
- **交付物**：CandidateSearchController
- **依赖**：3.3 职位发布、4.4 HR 投递管理

## 2. 简历模块

### 2.1 简历上传（附件）
- 2.1.1 文件接收（multipart，<=20MB，PDF / .docx）
- 2.1.2 文件存储（本地 ``）
- 2.1.3 元数据写入（resume_attachment 表）
- **交付物**：UploadController、FileStorageService
- **依赖**：8.4 文件上传

### 2.2 PDF/Word 文本抽取子进程（Python 软依赖）

> 本任务只负责 PDF/Word → 纯文本，不涉及 AI；AI 语义解析由 6.1（AI-1 简历解析）负责。
- 2.2.1 `tools/parse_resume.py`（pdfplumber + python-docx）
- 2.2.2 Java ProcessBuilder 集成
- 2.2.3 stdout JSON 协议（含 text 字段，供 6.1 使用）
- 2.2.4 失败回退（Apache PDFBox / POI，同样输出纯文本）
- **交付物**：tools/parse_resume.py、ResumeParseService
- **依赖**：2.1 上传、`docs/技术约束.md §11`

### 2.3 简历编辑
- 2.3.1 单一 ACTIVE 简历（`is_archived=false` 唯一）
- 2.3.2 重新上传流程（删除 → 归档 → 新建）
- 2.3.3 字段编辑（基本信息 / 教育 / 工作 / 项目 JSON / 技能 / 自我介绍）
- 2.3.4 归档可见性（ARCHIVED 仅 HR 在投递详情可见）
- **交付物**：ResumeController、ResumeEdit 页面
- **依赖**：2.2 Python 解析

## 4. 投递模块

### 4.1 投递（候选人）
- 4.1.1 投递动作（取 ACTIVE 简历副本）
- 4.1.2 AI 评分触发（一次性，详见 6.2）
- 4.1.3 投递信生成（扩展 AI-6）
- **交付物**：ApplicationController、ApplyBtn 组件
- **依赖**：2.3.1 ACTIVE 简历、3.3 职位发布、6.2 AI-2

### 4.2 投递状态机
- 4.2.1 8 状态枚举（PENDING_REVIEW / VIEWED_BY_HR / RESUME_PASSED / INTERVIEWING / OFFERED / HIRED / REJECTED / WITHDRAWN）
- 4.2.2 状态流转规则
- 4.2.3 状态时间线（application_status_history 表）
- **交付物**：ApplicationStatusService
- **依赖**：4.1 投递

### 4.3 撤回投递（候选人）
- 4.3.1 撤回按钮入口
- 4.3.2 任意非终态 → WITHDRAWN
- 4.3.3 自动站内信通知（系统 → HR）
- 4.3.4 WITHDRAWN 不可恢复
- **交付物**：WithdrawController、撤回确认弹窗
- **依赖**：4.2 状态机、5.1 会话

### 4.4 HR 投递管理
- 4.4.1 投递列表（按职位分组）
- 4.4.2 AI 评分展示（读 `ai_score` / `ai_reason`）
- 4.4.3 WITHDRAWN 显示（默认折叠 + 灰色）
- 4.4.4 状态推进
- 4.4.5 HR 内部备注（application_note 表）
- **交付物**：HrApplicationController
- **依赖**：4.2 状态机

### 4.5 投递时间线
- 4.5.1 状态时间线展示
- 4.5.2 WITHDRAWN 行展示
- **交付物**：TimelineService、Timeline.vue
- **依赖**：4.2 状态机

## 6. AI 集成模块

### 6.1 AI-1 简历解析

> 本任务是简历解析流程的第 2 步（纯文本 → 结构化 JSON）；第 1 步（PDF/Word → 纯文本）在 2.2。
- 6.1.1 触发位置（上传瞬间，仅一次）
- 6.1.2 提示词模板（JSON Schema）
- 6.1.3 失败降级
- **交付物**：LlmResumeParseService

### 6.2 AI-2 匹配评分
- 6.2.1 触发位置（投递瞬间，仅一次）
- 6.2.2 提示词模板（简历 + JD → 0-100 + 理由）
- 6.2.3 写入 application 表
- 6.2.4 失败降级（`ai_score=NULL` + "待评分"）
- **交付物**：LlmScoreService
- **依赖**：4.1 投递

### 6.3 AI-3 JD 生成 / 润色
- 6.3.1 一键润色按钮
- 6.3.2 提示词模板（关键词 / 标题 → JD）
- 6.3.3 失败降级（手动填写）
- **交付物**：LlmJdService
- **依赖**：3.3.2 JD 手动填写

### 6.4 AI-4 智能客服
- 6.4.1 悬浮聊天窗口
- 6.4.2 使用手册关键词检索 + LLM
- 6.4.3 SSE 流式输出
- **交付物**：LlmChatService、ChatWidget.vue
- **依赖**：`docs/技术约束.md §6`

### 6.5 AI-5 HR 批量回复（扩展）
- 6.5.1 批量选择候选人
- 6.5.2 基于简历 + JD 生成回信
- **交付物**：LlmBatchReplyService
- **依赖**：6.2、5.2

### 6.6 AI-6 投递信生成（扩展）
- 6.6.1 候选人投递时附加
- 6.6.2 基于简历 + JD 生成
- **交付物**：LlmCoverLetterService
- **依赖**：4.1 投递、6.2
