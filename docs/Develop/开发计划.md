### 3.1 关键包/类说明

| 包 / 类 | 职责 |
|---|---|
| `common.Result<T>` | 全局统一响应 `{code, message, data}` |
| `common.BusinessException` | 业务异常（被 `GlobalExceptionHandler` 转 `Result.fail(code, msg)`） |
| `common.annotation.*Required` | 方法级权限注解（AOP 拦截检查） |
| `common.context.CurrentUserContext` | ThreadLocal 持有 `userId` / `role` |
| `config.JwtFilter` | 解析 `Authorization: Bearer xxx` 写 ThreadLocal |
| `config.AuthInterceptor` | 检查方法注解 + ThreadLocal role 是否匹配 |
| `entity.*` | 19 张表对应实体，软删字段加 `@TableLogic` |
| `llm.LlmClient` | RestClient 封装，统一 30s 超时 + JSON 解析 + ai_call_log 写入 |
| `sse.SseEmitterManager` | 维护 `userId → emitter` 映射，25s 心跳 |

### 4.1 前端关键约定

- **Vue 3 Composition API + `<script setup>`**（项目已锁定）
- **禁止 `< v-html`**，所有动态内容用 `{{ }}` 插值（XSS 防护）
- **头像**：`<Avatar :user-id="...">` 组件按 user_id 哈希取色 + 首字符实时生成 SVG
- **HTTP 错误**：401 自动清 token + 跳登录；5xx toast 提示
- **本地开发代理**：`/api` → `http://localhost:8080`（Vite proxy）

## 8. 风险与回退方案

| 风险 | 影响 | 应对 |
|---|---|---|
| MySQL 未启动 / 端口占用 | 后端启动失败 | 启动前 `netstat -ano | findstr 3306` 确认 |
| LLM API Key 失效 / 调用失败 | AI 4 必做功能降级 | 失败降级策略已在功能设计文档定义 |
| 时间紧张 | 必做功能优先 | 优先完成 §5.A-F + I 必做，消息附件 / AI-5/6 可降级 |
| Python 解析简历失败 | UC-06 不可用 | 准备 Java Apache PDFBox / POI 回退（已在 §2 详细设计 §2.2） |
| 答辩当天 MySQL 挂了 | 演示灾难 | 准备离线 sqlite 备份或 docker 镜像 |
