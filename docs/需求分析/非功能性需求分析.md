## 1. 引言

### 1.1 编写目的

本文档描述"AI 集成的智能招聘系统"的非功能性需求，明确系统在性能、安全、可用性、可维护性与可扩展性等质量属性上的目标与衡量标准，定义支撑功能实现的关键技术决策，作为后续技术选型评审、性能与安全测试、运维方案设计的依据。

预期读者：课程指导教师、项目评审人员、开发人员。

### 1.2 项目背景

随着互联网招聘行业的发展，传统招聘流程存在以下痛点：

- 求职者手动填写大量简历字段，完成率低；
- HR 在大量简历中筛选候选人效率低下；
- 职位描述（JD）撰写质量参差不齐；
- 候选人投递后缺乏有效反馈通道；
- 用户在使用网站时遇到问题缺乏即时帮助。

本项目通过集成大语言模型（LLM）API 解决上述痛点，构建一个 AI 增强的智能招聘 Web 系统。

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| BCrypt | 密码单向哈希算法，用于密码安全存储 |
| JWT | JSON Web Token，前后端分离架构下的无状态认证方案 |
| SSE | Server-Sent Events，服务器向浏览器单向推送消息的技术 |

## 2. 项目概述

### 2.1 项目目标

构建一个三角色（求职者 / HR / 管理员）的 Web 招聘系统，在传统增删改查功能基础上集成 4 个核心 AI 功能（简历解析、匹配评分、JD 生成、智能客服），形成可演示、可答辩的完整应用。

### 2.2 项目范围

**包含：**

- 三角色 Web 招聘系统（求职者 / HR / 管理员）；
- 简历双轨管理（在线表单 + 附件上传）；
- 投递状态管理（求职者 / HR 共享数据，可见范围按角色区分）；
- 站内消息中心（前端交互形态参考主流即时通讯软件）；
- 4 个必做 AI 集成功能；
- 字典维护（行业 / 城市为强制字典；职业技能为自由输入，配可选建议池）。

**不包含：**

- 面试日程管理（通过消息中心或线下沟通解决）；
- HR 企业资质认证（简化为角色标识与公司信息审核）；
- 防骚扰机制（投递上限 / 黑名单 / 举报）；
- 简历隐私分级（默认所有 HR 可见已投递的简历）；
- 数据看板 / 漏斗可视化；
- 系统公告；
- 移动端 App（响应式布局即可）；
- 邮件 / 短信通知。

## 3. 非功能性需求

### 3.1 性能

- 列表页加载时间 < 2 秒；
- 搜索响应时间 < 1 秒；
- LLM 调用采用异步处理 + 前端进度提示（5–30 秒）。

### 3.2 安全

- 密码 BCrypt 哈希存储；
- 防 SQL 注入（MyBatis-Plus 参数化查询）；
- 防 XSS（前端转义）；
- 按角色进行权限控制；
- API Key 不进入代码仓库。

### 3.3 可用性

- 响应式布局（PC + 简单移动端）；
- 表单校验提示；
- 操作反馈提示（toast）；
- 空数据 / 错误状态页。

### 3.4 可维护性

- 关键操作日志；
- AI 调用日志（便于问题追溯与成果展示）；
- 全局异常处理；
- **数据生命周期管理**：采用软删（`is_deleted` 字段）+ 列表默认过滤 + 视图层"显示已结束"开关；ARCHIVED 简历与 WITHDRAWN / REJECTED 投递不直接删除，由管理员在后台定期硬删（演示阶段不实做，文档约定保留期不少于 6 个月）。
- 配置外部化（`${ENV_VAR:默认值}` 占位符）。

### 3.5 可扩展性

- LLM 提供方可切换（通义千问 / MiniMax，配置字段切换）；
- 文件存储先落地本地磁盘，预留对象存储（OSS）接口；
- 模块间松耦合。

## 4. 关键技术决策（NFR 视角）

> 本节仅收录与质量属性、技术架构相关的决策；与功能行为相关的决策（简历解析格式、AI 降级、验证码登录、公司审核）见《功能性需求分析》。

### 4.1 认证方案：JWT Token

- 采用 JWT 实现前后端分离架构下的无状态认证；
- 技术栈：Spring Security（轻量引入）+ jjwt 0.12.x。

### 4.2 文件存储：本地存储

- 存储路径通过 `${UPLOAD_DIR:./uploads}` 占位符配置；
- 课程项目不要求生产级可靠性，占位符设计便于将来迁移至 Linux 服务器或对象存储。

### 4.3 邮件功能：仅作为联系字段

- 不做邮箱验证与邮件通知，邮箱仅作为求职者联系信息存储（candidate_profile 必填字段，供 HR 查看）；
- 不做邮箱验证可避免 SMTP 配置复杂度；不做邮件通知可降低演示环境风险；
- 找回密码功能如需实现，采用其他方式。
