## 职位 1：Java 后端开发工程师

- **城市 / 省份**：北京 / 北京
- **行业**：互联网/IT
- **薪资**：30-55K
- **关键词**：Java, Spring Boot, MySQL, Redis, Kafka, Kubernetes, 微服务, 高并发, 分布式, 字节, 美团

**岗位职责**：
负责公司核心业务后端服务的设计与开发，参与分布式系统架构演进，支撑高并发场景（QPS 50 万+）。

**任职要求**：
1. 5 年以上 Java 后端开发经验，熟悉 Spring Boot / MyBatis；
2. 精通 MySQL / Redis / Kafka / RocketMQ 等中间件；
3. 有 Kubernetes / Docker / 微服务架构经验；
4. 有高并发 / 分布式系统设计经验；
5. 大厂背景优先。

3. 有完整品牌视觉系统建设经验，熟悉设计 Token / 设计规范；
4. 大厂（字节 / 阿里 / 腾讯 / 蚂蚁 / 拼多多）背景优先。
